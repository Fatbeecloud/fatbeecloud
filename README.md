## 手机和电脑怎么用

先装一个连接 VPN 用的 App：

| 你的设备 | 装这个 App |
|---|---|
| iPhone / iPad | Shadowrocket（俗称“小火箭”，要用国外的 Apple ID 在 App Store 购买） |
| 安卓手机 | FlClash 或 v2rayNG |
| Windows 电脑 | Clash Verge Rev 或 v2rayN |
| 苹果电脑 | Clash Verge Rev |

**三步就能用：**

1. 装好上面对应的 App。
2. 登录 <https://panel.fatbeecloud.com>，在首页点「一键订阅」，选你装的 App，会自动把所有线路导入进去。
3. 在 App 里选一个地区，打开开关，就连上了。

**小提示：**

- App 里的模式选「**规则**」，别选「全局」。这样国内的网站和 App 不绕路，不会变慢。
- 线路有调整时，在 App 里点一下「**更新订阅**」就行，不用重新导入。
- 你的订阅链接就相当于账号，**不要发给别人**。

网站里有每个 App 的图文教程，一步一步跟着做就行。
