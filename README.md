## 为什么选胖蜜蜂云

| | 胖蜜蜂云 | 一般的大众机场 |
|---|---|---|
| 注册方式 | **邀请制**，每位会员每天只能生成 1 个邀请码 | 开放注册，人越多越挤 |
| 用户数量 | **严格限量、不超售** | 靠人数摊薄成本，晚高峰容易卡 |
| 线路 | 香港三网 CN2 回程、美国 CN2 GIA / 9929 / CMIN2 等优化线路 | 多为普通线路 |
| AI 和 Google | Google、Gemini、ChatGPT、Claude 专门分流，避开“送中”和地区限制 | 经常遇到 google.cn 跳转、“地区不支持” |
| 付款 | 支付宝付款，**付完自动开通** | — |

**为什么邀请码限量？** 速度好不好，关键看一台服务器上挤了多少人。胖蜜蜂云宁可少收用户，也要保证每个人的体验，所以邀请码每人每天只能生成 1 个，总人数始终可控。

## 客户端怎么用

| 设备 | 推荐客户端 |
|---|---|
| iPhone / iPad | Shadowrocket（需外区 Apple ID 购买） |
| 安卓 | FlClash 或 v2rayNG |
| Windows | Clash Verge Rev 或 v2rayN |
| macOS | Clash Verge Rev |

**三步上手：**

1. 安装上表里对应的客户端。
2. 登录会员中心首页，点「一键订阅」，选你的客户端自动导入（或复制订阅地址粘贴进去）。
3. 选一个节点，打开开关。

**小贴士：**

- 模式选**规则**，不要用「全局」，国内网站和 App 才不会变慢。
- 节点有调整时，在客户端里**更新订阅**一次就行。
- 订阅地址等于你的账号，不要发给别人。

会员中心里有每个客户端的图文教程。

## 常见问题

**Q：为什么必须要邀请码？**
A：为了控制人数、保证速度。人少才能快，这是胖蜜蜂云的核心。

**Q：公开邀请码都被用完了怎么办？**
A：在本仓库的 [Issues](https://github.com/Fatbeecloud/fatbeecloud/issues) 里留言，站长会补发。

**Q：连不上怎么办？**
A：先看套餐是否到期、流量是否用完 → 在客户端更新订阅 → 换一个节点 → 切换 Wi-Fi / 手机流量。还不行就在会员中心「我的工单」联系站长。

**Q：能用 ChatGPT、Gemini、Claude 吗？**
A：可以，这些服务已经专门分流到支持地区的出口。

**Q：支持微信付款吗？**
A：目前只支持支付宝，付款后自动开通。

**Q：可以几台设备一起用？**
A：同一时间最多 5 台。
